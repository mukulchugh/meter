# Meter icon concepts

- **A · Resting gauge** ([icon-a.png](icon-a.png)): one calm arc and one precise needle turn many costs into a single trusted reading.
- **B · Measured reserve** ([icon-b.png](icon-b.png)): a still teal level in a glass vessel makes available budget feel tangible.
- **C · Converging flows** ([icon-c.png](icon-c.png)): two translucent streams meet in one measure, expressing consolidated spend.

The original three are 1024 × 1024 PNG explorations with transparency, one teal accent family, and no lettering.

## Final: light gauge

Preserved A's light frosted glass, broad teal arc and resting needle, with deeper teal surfaces for small-size contrast.  
Removed the speckled perimeter and applied a crisp rounded-square alpha boundary with an 824 px tile and 100 px transparent margins.  
Verified fully transparent exterior pixels and 16 px light/dark composites; retained the previous dark master as an alternate.

Final artwork: [meter-icon-1024.png](../icon/meter-icon-1024.png). B and C remain concept studies; use the final artwork for shipping.
